# Портфолио на Гелиосе

https://se.ifmo.ru/~s564064/ - деплоится сам после пуша в `main`.

Чистые HTML + CSS + JS, без сборки: файлы отдаются как есть. Все пути относительные.

## Где что лежит

| Путь | Что это |
|---|---|
| `index.html` | Главная |
| `images/` | Картинки |
| `assets/style.css` | Общие стили: цвета, шапка, боковая панель, карточки, поля, кнопки |
| `assets/works.js` | Список работ. По нему строятся боковая панель, список на главной и «пред / след» внизу работы |
| `works/<slug>/index.html` | Страница работы |
| `works/<slug>/style.css` | Стили только этой работы |
| `works/_template/` | Заготовка новой работы |

## Как добавить работу

1. Скопировать `works/_template/` в `works/<slug>/` (slug - латиницей, например `correlation`).
2. В `index.html` новой папки: заменить `НАЗВАНИЕ`, а в `<body data-work="...">` вписать slug.
3. Добавить строку в `WORKS` в `assets/works.js`:
   ```js
   { slug: 'correlation', title: 'Корреляция', task: 'https://...', editor: 'https://...' },
   ```
   `task` - ссылка на условие задания, `editor` - на выполненное задание в онлайн-редакторе.
   Обе необязательны: без них кнопки внизу страницы просто не появятся.

Порядок в `WORKS` = порядок в меню и в «пред / след».

## Правила заданий

- `<!DOCTYPE html>` на каждой странице.
- Не использовать `console` и `searchParams`.
- Не называть переменные `top`, `name`, `status`, `length`, `parent`, `self`, `origin`.
- Логин в `<h4>`: `malodushev_m`.
